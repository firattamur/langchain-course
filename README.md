# LangChain Course

Welcome to the LangChain Course! This repository provides practical resources and examples to help you learn and apply LangChain for building AI-powered applications.

## Features

- Step-by-step tutorials and exercises
- Example projects using LangChain
- Guidance for environment setup with Python 3.13, VS Code Insiders, and uv

## Quick Start

1. Install [VS Code Insiders](https://code.visualstudio.com/insiders/).
2. Install [uv](https://github.com/astral-sh/uv) (recommended via Homebrew):
   ```zsh
   brew install uv
   ```
3. Sync dependencies:
   ```zsh
   uv sync
   ```
4. Explore the course materials and run the example scripts.

## Requirements

- Python 3.13+
- macOS, Linux, or Windows
