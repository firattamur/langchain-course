# LangChain Course - Lecture 01

This project contains code and resources for Lecture 01 of the LangChain course.

## Getting Started

1. Clone the repository.
2. Install [VS Code Insiders](https://code.visualstudio.com/insiders/).
3. Install [uv](https://github.com/astral-sh/uv) (recommended via Homebrew):
   ```zsh
   brew install uv
   ```
4. Sync project dependencies:
   ```zsh
   uv sync
   ```
5. Run the lecture scripts as needed.

## Overview

- Introduction to LangChain concepts
- Example scripts and exercises
